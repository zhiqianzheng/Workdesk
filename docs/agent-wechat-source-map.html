长连接推送源码存在连接、通知、同步拉取和断线回退路径。不能证明你当前账号正在使用推送，或所有账号都已验证可用。
同步进度“收到批次”和“成功写回”的进度分别管理。拿到新游标不等于每条数据都已写入，也不等于拿到了全部历史。
accepted服务端接受，且回执与本次请求关联匹配。不等于好友已经阅读。
幂等键同一账号、同一任务标识复用既有发送意图，避免重复创建。不能承诺端到端绝对只发送一次；结果未知不能盲目重试。
加密存储敏感控制记录绑定账号和用途加密；聊天 profile 另有密钥与格式检查。不能把整份目录都当成无敏感信息；密钥和登录态仍需保护。
