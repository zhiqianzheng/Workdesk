# Workdesk v1.1.0-preview.12

桌面接管与聊天体验更新，包含已合并的 PR #22、#23。

- 联系人接管范围即时生效，明确显示勾选与保存结果，支持一键接管/取消、搜索、好友/群聊筛选和只看已接管；筛选不清除隐藏对象的选择。
- API 授权按地址保存，重开保留；更换地址重新确认。回复能力与接口设置仍需保存，界面明确说明。
- 修复会话列表滚轮带动整页、下拉框滚轮误选；点击联系人不再自动收起网页目录。
- 调整聊天表达，减少文案式总结、机械安慰与追问，保留按语境主动使用表情与图片的能力。
- 群聊默认仅在 @ 当前账号或引用本账号消息时回复，可在设置关闭后保存。
- 本人在微信客户端新发言后，对应会话让开 10 分钟；状态页显示人工接管。后台 API 发送、旧消息和控制口令不触发。已经提交的发送无法撤回。
- 新增试聊预览：使用已保存的接口与风格，仅本机显示，不向微信发送，也不调用联网或图片工具。
- 桌面与个人口令配置修改使用跨进程锁和原子替换，减少并发覆盖。

## 下载与验证

Ubuntu amd64 DEB 与 Windows x64 ZIP 分别附 SHA-256 校验文件。升级保留用户配置和消息游标，安装前请等待任务空闲并关闭旧控制台。

本地 107 项 Python 检查和 6 项前端检查通过；双平台构建会执行回归与打包自检。人工接管的真实微信客户端事件和 Windows 实际微信操作仍需目标环境验收，模拟测试不代表所有微信版本兼容。API 监听健康不代表模型服务当前可用，可用“测试对话连接”检查。

本次为桌面预览版，不更新 Android APK；不包含自动更新或完整版本回退功能。
