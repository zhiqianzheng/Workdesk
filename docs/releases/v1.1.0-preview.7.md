# Workdesk v1.1.0-preview.7

- 新增文件传输助手独立个人通道：本人新消息进入模型对话，支持现有联网、视觉、生成图片、文本附件和普通视频抽帧能力；个人助手与好友/群聊暂停分开控制。
- 新增微信语音本地转写后自动文字回复，随包提供 whisper.cpp v1.9.5 与多语言 base 模型，可选普通话、英语或自动检测。最多 120 秒、8 MB；识别可能出错。
- 新增个人通道状态、独立启停口令与发送结果待核对机制；自发反馈不触发循环，首次开启不重放旧消息。
- 扩展个人对话输出长度，长文字分段发送；保留好友群聊的简洁表达。
- Windows 与 Linux 共用原生后台实现；UIA/OCR 不支持新增个人通道/语音。Windows 包含本地语音组件，完整解压后使用。

能力依赖所配置模型/API与开关；不是 Codex 终端代理，不支持通过聊天自动安装软件或执行任意本机命令。视频号分享仍只提供卡片元数据，普通视频只抽帧、不分析音轨。原有用户新增开关默认关闭，升级保留已有暂停状态。

验证：合成消息回归、自发循环与本人身份验证、暂停隔离、发送去重，以及本地中英文录音识别；构建执行桌面、视频和真实录音自检。实际微信语音媒体下载与 Windows 实机微信收发仍需目标机器验收。发行包不含开发者密钥、微信账号或聊天记录。
