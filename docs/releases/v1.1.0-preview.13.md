# Workdesk v1.1.0-preview.13

历史分析功能收敛为两项：聊天总结报告与联系人专属聊天风格学习。核心微信连接、API配置、接管范围、媒体和手动暂停保持。

- 聊天报告支持日期范围、最近N条与全部已同步记录，不设总条数上限；分页落盘、长消息拆分、分批汇总，支持进度、取消、查看和导出。附本机来源索引，长请求等待180秒，空发言者和缺失时间不再导致崩溃。
- 联系人风格从主人确认的本人样本学习，对方消息只作上下文；分批处理全部选中样本，显示进度、屏蔽凭据、使用短证据编号、重试不完整JSON。结果可编辑，确认应用后跨重启持续用于对应会话。
- 停用自动记忆/向量召回、历史事实记忆导入、审批、偏好备份恢复与试聊入口。已有私有数据保留，不自动使用或发送；历史限制状态保守保留。
- 取消人工发言后自动让开10分钟，旧让开记录不再生效。只有明确的暂停操作/口令才改变暂停状态。
- 改善多轮接话：避免重复同一段子、emoji和自评式解释；普通闲聊允许自然收尾不再回复，个人助手任务通道不使用该静默机制。若对方在生成期间发来新消息，旧答复重新合并处理。
- 按话题和情绪主动使用emoji/反应图，不设随机或固定频次。去掉图片默认套话，表情只发图片，不另发配文或素材链接；OpenMoji出处以图内角标保留。

## 验证与边界

本地150项Python与6项前端回归通过；双平台构建执行回归和打包自检。真实API已验证聊天报告、风格分析与语境主动表情选择，未向联系人发送测试消息。聊天风格不等于模型微调，不保证每条回复像本人或无法识别AI；直接问身份仍如实说明。

仅分析本机后台已同步的历史，附件不下载分析；报告可能遗漏或误判，应核对原记录。历史/报告/样本发送到用户配置的API处理，私有数据、登录态和密钥不随源码或安装包分发。

Windows x64 ZIP和Ubuntu amd64 DEB附SHA-256文件。本次不更新Android APK。升级前等待任务空闲并关闭旧控制台；保留已有用户配置与消息游标。
