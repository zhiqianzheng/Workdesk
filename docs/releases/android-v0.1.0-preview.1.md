# Workdesk Android 0.1.0-preview.1

首个原生安卓独立文字预览版，适用于 Android 9 及以上，不依赖电脑端 Workdesk（若使用电脑自建 API，电脑仍须在线）。APK 使用持续更新签名，附 SHA-256 校验文件；默认不配置任何 API、不接管任何会话。

- API URL/Key/模型配置、本机加密保存、文字连通性测试和模型查询。
- 接管名单内的新微信通知文字自动回复；通知须实际提供快捷回复入口。可选前台辅助需要单独授权、亮屏解锁，会打开微信并核对会话及草稿。
- 独立 AI 文字对话；可选 Responses 联网检索；共用桌面自然表达与 emoji 规则。
- 明确的状态与运行记录、暂停取消未发送任务、去重和不重试未知发送。

安卓首版不支持自动发图片、语音转写、视频/文件分析、完整历史、文件传输助手接管与本人微信口令；不与桌面开关联动，不保证静音、隐藏通知、锁屏或厂商后台限制下可用。不要与电脑端同时接管同一会话。

构建含 lint、签名验证与 Android 模拟器基本验收。完整通知链路使用隔离模拟器的合成通知，不代表已验证所有真实微信版本；前台辅助仍需实际手机验收。安装与授权步骤见 android/README.md。包中没有开发者密钥或微信账号。
