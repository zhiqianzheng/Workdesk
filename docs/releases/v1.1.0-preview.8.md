# Workdesk v1.1.0-preview.8

- 移除“只有对方明确索要才发图”的限制。开启图片回复后，助手可根据当前话题与情绪主动调用图片生成或在线表情素材，仍可只发文字，不按时间、轮数或概率安排。
- 扩展聊天表达规则：区分分享、吐槽、玩笑、难过与认真求助；减少客服式共情、机械追问与无意义建议，允许贴合语境的 emoji，避免不合场合的调侃和虚构经历。
- 好友/群聊上下文保留近期已发送图片的记录，不重新下载、不把媒体元数据当正文；个人通道在确认发送成功后保留图片记录，供下一轮判断，减少重复。
- 本机开关、本人身份核验、暂停与图片发送确认机制保持生效。Windows/Linux 原生后台共用实现，UIA/OCR 仍只支持已有文字能力。

验证：95 项 Python 回归、6 项前端回归及双平台包内自检。表达效果由模型与具体对话决定，不保证每次选图或语气都恰当；不通过随机频率模拟自然。在线素材仍保留所需署名。
