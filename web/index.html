本地连接与使用说明

连接方式
优先使用本机文字控件；不可用时自动使用 Windows OCR。接收的文字和预览只在内存中处理，不上传到其他服务。发送图片时临时使用剪贴板，完成后恢复原内容；期间若你复制了新内容，会保留新内容。粘贴时可能短暂切换到微信，不再打开文件选择窗口。
记录范围
文字控件可用时支持联系人搜索和会话切换；图片显示当前窗口预览。OCR 降级模式仅有可见文字，不是完整历史备份。
文字提交
“提交记录”会真实发送。发送时会先清空当前聊天的原窗口草稿；对象变化或接口不可用时停止。状态未知时请先到原窗口核对。
切换笔记
Esc 或 Ctrl+Shift+Space，仅在此网页获得焦点时生效。不会隐藏微信自身窗口、通知或任务栏。
兼容性
OCR 需要原窗口保持打开且未最小化，可以被工作台覆盖。发送时短暂激活原窗口；目前支持每条 200 字以内的单行文字，校对失败会保留草稿。

项目别名

只改变工作台显示，不修改微信备注。

图片预览

来自当前窗口的预览；原图请在微信中打开。

记录详情

按读取顺序显示原文，保留消息边界与时间文字。图片请从正文附件入口查看。
